Research questions

세 질문, 네 가설

주효과 하나로 끝내지 않는다. 성능, 시각적 전환 비용, gaze의 incremental value, 개인차를 분리한다.

RQ1 · performance

선택적 보조가 실제 오류를 줄이는가?

접촉·drop·placement error와 불필요한 중지를 비교한다. completion time만 빠른 것을 성공으로 보지 않는다.

RQ2 · visual cost

정보를 덜 펼치고도 충분히 볼 수 있는가?

view transition, gaze transition, 화면 탐색시간, camera churn, NASA-TLX를 비교한다.

RQ3 · incremental value

gaze가 geometry보다 추가 정보를 주는가?

C3와 C2의 차이를 핵심 비교로 둔다. 가림률과 TCP 거리만으로 같은 효과가 나면 gaze 기여는 성립하지 않는다.

사전등록할 가설

H1. Always-multi는 manual-switch보다 task success를 높일 수 있지만 gaze transition과 workload를 증가시킨다. H2. Geometry-only와 Sightline은 always-multi 대비 task success를 유지하면서 view/gaze transition을 줄인다. H3. Sightline은 geometry-only 대비 “필수 AOI가 실제로 미검사인 trial”에서 false continuation과 접촉 오류를 줄인다. H4. 효과는 novice와 높은 occlusion 조건에서 크고, expert·clear-view 조건에서는 작거나 방해가 될 수 있다.

주 분석 우선순위: H3가 핵심이다. H1·H2만 지지되면 “적응형 camera UI”의 가치이지 Tobii의 가치가 아니다.

Independent variable

네 조건으로 원인을 분리

single fixed view는 파일럿의 난이도 확인용 negative control로 둘 수 있지만, 본 실험의 강한 기준선은 manual-switch와 always-multi다.

모든 조건에서 같은 camera stream, controller mapping, robot speed, task order를 사용한다. 달라지는 것은 화면 선택 규칙뿐이다.

동일한 cue

C2와 C3의 보조 view 크기·위치·animation·표시시간을 동일하게 유지해 trigger 정보만 비교한다.

Hysteresis

view가 뜬 뒤 최소 표시시간과 cooldown을 둔다. 매 fixation마다 화면이 흔들리는 camera churn을 방지한다.

Manual override

모든 조건에서 운영자는 보조 view를 닫거나 직접 선택할 수 있다. override 횟수도 결과로 기록한다.

Task battery

가림의 종류가 다른 세 작업

한 종류의 block pick-and-place만 쓰면 특정 물체 배치에 과적합된 UI가 된다. transport, contact alignment, result verification을 분리해 난이도를 조절한다.

T1 · pick & place

목표 자체 가림

유사한 폼 블록 중 지정 블록을 집어 bin에 놓는다. 팔 또는 gripper가 목표 중심을 가리는 배치를 만든다.

  • 오류: wrong grasp, drop, bin wall contact
  • 필수 view: overhead → wrist/side
T2 · stacking

높이·정렬 모호성

블록 위에 다른 블록을 지정 tolerance 안에 놓는다. overhead만으로는 z-gap과 edge alignment가 약하다.

  • 오류: collision, tilt, offset
  • 필수 view: overhead + side
T3 · slot insertion

접촉면 정밀도

가벼운 peg를 넓은 slot에 삽입한다. 힘이 필요한 press-fit은 제외하고 저위험 tolerance로 설계한다.

  • 오류: rim contact, failed insertion
  • 필수 view: wrist + side

Trial flow

개입이 결과보다 먼저 일어나야 한다

gaze로 오류 뒤의 놀람 반응을 보고 assistance를 정당화하지 않는다. 보조 trigger, 운영자 반응, 물리 결과의 시간 순서를 명확하게 고정한다.

C0/C1에서는 trigger를 shadow mode로 계산해 표시하지 않고 저장하면, 동일 trial에서 “언제 떴을 것인가”를 비교할 수 있다.

Calibration & validation

블록 시작 전 보정하고 validation error를 저장한다. 일정 trial마다 drift check를 하며 사전 정의 기준을 넘으면 재보정한다.

Preview

목표·도착지·controller mapping을 표시한다. 초기 fixation cross와 home pose를 맞춰 trial 시작 상태를 통제한다.

Free teleoperation

참가자가 xArm을 조작한다. 시스템 조건에 따라 view를 표시하지만 robot command는 바꾸지 않는다.

Outcome lock

물체를 놓거나 제한시간·E-stop·fault가 발생하면 trial을 종료하고 camera/robot/gaze stream을 같은 event ID로 고정한다.

Micro-rating

일부 trial에서 방해·놀람·통제감을 짧게 묻고, block 종료 후 NASA-TLX와 선호·신뢰를 측정한다.

Dependent variables

속도 하나로 UI를 판단하지 않기

빠르지만 많이 부딪히는 UI도, 안전하지만 계속 화면을 바꾸는 UI도 좋은 시스템이 아니다. 성능·시각행동·자동화 비용·주관경험을 분리한다.

Analysis plan

참가자와 장면을 동시에 일반화

같은 사람이 여러 조건·작업을 반복하므로 trial을 독립 표본처럼 분석하면 안 된다. participant와 scene/task를 random effect로 둔다.

Confirmatory models

  • 성공/접촉: mixed-effects logistic 또는 count model
  • 시간/경로: log-transform 또는 적절한 GLMM
  • transition/workload: mixed-effects model
  • 고정효과: condition, occlusion, task, expertise, interaction
  • random intercept: participant, scene; 필요 시 random slope

Planned contrasts

  1. C1 − C0: 다중뷰의 정보/부하 trade-off
  2. C2 − C1: 선택적 기하 보조의 가치
  3. C3 − C2: gaze의 incremental value
  4. high − low occlusion에서 C3 효과 차이

표본수

임의로 “30명”을 확정하지 않는다. 6–8명의 기술 파일럿으로 오류율과 within-subject variance를 추정한 뒤, H3의 최소 관심효과를 기준으로 simulation-based power analysis를 수행한다. 파일럿 참가자는 confirmatory sample에서 제외하거나 사전 명시한다.

다중 비교와 제외 규칙

주 contrast는 C3−C2와 primary outcome으로 제한한다. tracking ratio, calibration error, emergency stop, hardware fault에 따른 trial 제외 규칙을 데이터 열람 전에 고정하고, 제외 전후 sensitivity analysis를 함께 보고한다.

Validity threats

좋은 결과처럼 보이게 만드는 함정

UI 연구는 학습·순서·현저성·novelty effect에 특히 취약하다. 구현보다 먼저 통제 계획을 적는다.

Order & learning

Latin-square로 condition 순서를 균형화하고, 각 task에 연습 trial을 둔다.

Salience confound

보조 view animation과 색을 C2/C3에서 동일하게 하고, AOI 위치·크기를 균형화한다.

Experimenter bias

fault와 occlusion 배치를 script로 생성하고, outcome scoring은 condition을 가린 영상으로 이중 검수한다.

Novelty effect

첫 보조 cue의 놀람을 분리하고 block 후반 성능을 별도 보고한다.

논문 단위의 결론: “Sightline이 좋다”가 아니라, 어떤 시점·가림·숙련도에서 gaze-informed selective view가 geometry-only 대비 어떤 비용으로 어떤 오류를 줄이는지 보고한다.
