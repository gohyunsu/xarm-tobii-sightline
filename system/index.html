Physical rig

작업 셀과 운영석을 물리적으로 분리

Software boundaries

gaze와 motion 사이에 권한 경계 두기

단일 프로세스가 eye tracking, UI, robot control을 모두 맡으면 실수로 gaze가 운동 명령에 섞일 수 있다. 데이터 경로와 command 경로를 별도 process와 message namespace로 분리한다.

Windows · Tobii capture client

  • 허가된 SDK로 gaze sample·validity 수신
  • monitor geometry와 calibration metadata 기록
  • local monotonic timestamp 부여
  • gaze.samples read-only stream 발행
  • robot IP·command credential 보유 금지

Ubuntu · ROS 2 robot backend

  • xArm state, TCP, gripper, error stream
  • camera frame과 calibration
  • controller input, clutch, dead-man switch
  • velocity/workspace/singularity guard
  • robot.command는 controller gateway만 발행

Experiment orchestrator

  • participant/trial/condition state machine
  • task phase와 AOI version 관리
  • risk·coverage 계산과 shadow trigger
  • event ID 및 동기화 heartbeat
  • 데이터 누락 시 fail-closed logging

Operator UI

  • main camera와 보조 view renderer
  • C0–C3 layout policy
  • controller 상태·robot error 표시
  • gaze cursor는 실험 중 숨김
  • 모든 자동 view 이벤트와 override 기록
권한 규칙: gaze process는 화면 이벤트만 요청할 수 있다. robot backend는 gaze topic을 subscribe하지 않는다. camera가 motorized여도 gaze만으로 servo command를 보내지 않으며 본 연구의 MVP는 고정 camera stream 선택을 우선한다.

Risk model

처음에는 설명 가능한 규칙으로

데이터가 거의 없는 상태에서 black-box failure predictor부터 학습하면 실험 조건이 모델 오류에 종속된다. geometry와 task phase로 해석 가능한 점수를 먼저 만든다.

구성요소

신호예시 계산뜻
ProximityTCP/gripper–target surface distance접촉까지 얼마나 가까운가
Time-to-contactdistance / projected approach speed보조 view를 볼 시간이 남았는가
Occlusioncritical mask 중 robot mask와 겹치는 비율현재 main view가 증거를 가리는가

정규화된 점수 예시

risk_t = w_p·proximity + w_c·time_to_contact + w_o·occlusion + w_s·phase_gate

가중치는 파일럿 전에 정하고, 데이터에 맞춰 임의 조정하지 않는다. control instability는 사람이 어려움을 겪은 뒤 나타날 수 있으므로 주 trigger보다 탐색적 분석에 둔다.

risk ≠ safety: 이 점수는 camera assistance를 언제 보여줄지 정하는 실험 변수다. 충돌 방지는 xArm 제한, controller guard, MoveIt/SDK, E-stop이 별도로 담당한다.

Inspection coverage

AOI는 task phase에서 정의한다

화면에서 눈이 어디에 있었는지를 물체 전체 box 하나로 줄이지 않는다. transport와 contact에서는 필요한 증거가 다르다.

Dynamic AOI

robot/object detection과 camera calibration으로 polygon을 프레임마다 갱신한다. 일정 비율은 사람이 검수한다.

Uncertainty margin

gaze accuracy와 AOI 크기를 반영해 hard hit뿐 아니라 Gaussian overlap 또는 dilated AOI sensitivity를 보고한다.

Invalid gaze

결측을 “안 봄”으로 간주하지 않는다. tracking quality가 기준 아래면 C3 assistance를 geometry-only fallback으로 전환하고 이벤트를 기록한다.

Interface behavior

보조는 작고, 느리고, 되돌릴 수 있게

화면이 갑자기 크게 바뀌면 깊이 지각과 controller mapping이 깨질 수 있다. view assistance는 정보량보다 예측 가능성이 중요하다.

Picture-in-picture

main view를 유지하고 필요한 side/wrist view를 화면 20–30% 크기로 확장한다.

Stable placement

보조 view의 화면 위치를 고정해 매번 다시 찾지 않게 한다.

Hysteresis

표시 최소시간, 해제 threshold, cooldown을 별도로 둬 깜박임을 막는다.

Explicit override

운영자가 hotkey로 고정·닫기·다른 view 선택을 할 수 있게 한다.

표시하면 안 되는 것

  • 실시간 gaze cursor: 참가자의 자연스러운 시선을 바꾸고 target indicator처럼 작동한다.
  • “안전” 녹색 체크: assistance가 뜨지 않은 것을 안전 보증처럼 오해하게 한다.
  • 화면 전체 flash: attentional capture와 startled control을 만든다.
  • 시선으로 자동 클릭: Midas touch를 운동 결정에 연결한다.

Time synchronization

20 ms 차이가 원인과 결과를 바꿀 수 있다

gaze가 view cue 전에 일어났는지 뒤에 끌려갔는지 구분해야 한다. 각 device timestamp를 보존하고 공통 clock으로 변환한 residual을 기록한다.

Local timestamp at source

Tobii callback, camera capture, controller input, xArm state가 생성된 시점에 각 monotonic clock으로 timestamp를 붙인다.

Clock mapping

동일 machine은 monotonic clock, 여러 machine은 PTP/NTP 또는 검증된 sync layer로 offset·drift를 추정한다. 단순 수신시각만 쓰지 않는다.

Event markers

trial start, view cue, manual switch, grasp, release, collision을 공통 event ID로 발행한다.

Sync audit

LED/visual marker와 controller pulse 같은 관찰 가능한 동시 이벤트로 end-to-end residual을 파일럿마다 측정한다.

사전 Gate: end-to-end sync residual이 주 관심 효과의 시간 규모에 비해 충분히 작지 않으면 online trigger 연구를 시작하지 않는다. 먼저 offline shadow-mode 분석으로 전환한다.

Leakage-safe split

같은 사람·장면·배치의 인접 trial이 train/test에 섞이지 않도록 participant와 scene을 group split한다.

Versioned AOI

detector·calibration·task graph 버전을 저장해 같은 gaze sample을 다른 AOI 정의로 재분석할 수 있게 한다.

Privacy by design

얼굴 영상은 기본 수집하지 않고 participant ID를 무작위화한다. 동의서와 gaze data를 분리 보관한다.

Safety & failure handling

센서가 끊겨도 로봇은 예측 가능해야 한다

Tobii와 camera assistance는 안전 계층이 아니다. 실패하면 자동성이 늘어나는 것이 아니라 익숙한 manual baseline으로 내려가야 한다.
