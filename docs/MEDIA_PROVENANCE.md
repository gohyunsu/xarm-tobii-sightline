## 표시 규칙

1. 외부 연구 그림에는 `선행연구 그림 · 우리 결과 아님`을 표시한다.
2. 제조사 자료에는 `공식 제조사 자료 · 우리 실험 아님`을 표시한다.
3. caption에서 해당 자료가 연구 설계의 어떤 부분을 설명하는지 명시한다.
4. 외부 미디어가 없어도 본문과 자체 SVG만으로 핵심 논리가 이해되어야 한다.
5. 논문·발표 자료로 다시 배포하기 전 원 저작권과 라이선스를 별도 확인한다.
