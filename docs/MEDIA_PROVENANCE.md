## Display rules

1. Every prior-research figure is labeled `Prior-work figure · not our result`.
2. Every manufacturer asset is labeled as official media and not a Sightline experiment.
3. Captions state the narrow explanatory purpose of the asset.
4. Core reasoning remains understandable without any external media.
5. License terms must be rechecked before republishing an external asset in a paper, slide deck, dataset, or commercial site.
